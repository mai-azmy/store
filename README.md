online store project
This is onloine store web Application developed using PHP,HTML,CSS,bootstrap,js and Mysql The project simulates a real e-commerce
website where users can browse products and interact with the system 
features
Display products
product database using Mysql
simple and clean user interface
Backend functionality using PHP
Technologies used:PHP,HTML,CSS,bootstrap,js and Mysql
How to run 
Install a local server Xampp
place the project folder inside htdocs
start Apache and Mysql from the control panel
open Phpmyadmin
create a database
import the products.sql file into the database make sure database coonection setting in the project are correct
open the browser and go to 
http://localhost/your-project-folder
